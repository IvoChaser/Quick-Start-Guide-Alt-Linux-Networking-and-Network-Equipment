# Маршрутизация и NAT

## Цель
Понять маршрутизацию данных и способы трансляции адресов.

## Темы

### Основы маршрутизации
- **Маршруты** — определяют путь для передачи пакетов от источника к получателю в сети.
- **Статическая маршрутизация** — маршруты задаются вручную администратором; подходит для небольших сетей.
- **Динамическая маршрутизация** — автоматическое обновление маршрутов с использованием специальных протоколов, подходит для больших и сложных сетей.

### Протоколы маршрутизации
- **RIP (Routing Information Protocol)**:
  - Простой протокол для небольших сетей.
  - Использует количество переходов (hop count) как основной параметр.
- **OSPF (Open Shortest Path First)**:
  - Более сложный протокол, оптимален для больших сетей.
  - Определяет маршруты с использованием алгоритма кратчайшего пути (Dijkstra).

### Network Address Translation (NAT)
- **NAT** — технология, преобразующая частные IP-адреса в публичные для выхода в интернет.
- **Типы NAT**:
  - **SNAT (Source NAT)** — изменяет исходный IP-адрес (например, приватный на публичный).
  - **DNAT (Destination NAT)** — изменяет IP-адрес назначения, полезно для внешнего доступа к внутренним ресурсам.
  - **PAT (Port Address Translation)** — позволяет использовать один публичный IP для множества устройств, добавляя к IP адрес порта.

### Практика

1. **Настройка маршрутизации и NAT на симуляторах**:
   - Используйте симуляторы (Cisco Packet Tracer, GNS3, EVE-NG) для настройки статической и динамической маршрутизации.
   - Настройте NAT на маршрутизаторах и протестируйте преобразование адресов.

2. **Анализ работы с помощью инструментов**:
   - **Wireshark** — для анализа сетевых пакетов и понимания маршрутов через NAT.
   - **Traceroute и Ping** — для отслеживания маршрута пакета и проверки соединения.

## Рекомендации
Начните с настройки статической маршрутизации и простого NAT. Далее переходите к более сложным темам, таким как OSPF и PAT, для уверенного освоения маршрутизации и трансляции адресов.
