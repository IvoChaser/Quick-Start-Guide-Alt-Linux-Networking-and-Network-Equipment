# Шпаргалка по CIDR и VLSM

### 1. CIDR (Classless Inter-Domain Routing)

**CIDR** — метод адресации, который позволяет отходить от жёсткой системы классов IP-адресов (A, B, C) и создавать сети произвольного размера с помощью гибких масок.

#### Основные принципы CIDR

- **Гибкость масок**: CIDR позволяет создавать сети с любой длиной префикса, например, `/22`, `/28`, `/16`. Это помогает использовать только необходимое количество IP-адресов, избегая потерь.
- **Запись CIDR**: CIDR записывается в формате `IP/префикс`. Например, `192.168.1.0/24` означает, что первые 24 бита адреса используются для обозначения сети, а остальные 8 бит — для хостов.
- **Оптимизация адресного пространства**: CIDR позволяет экономить IP-адреса, создавая подсети с нужным количеством адресов. Например, сеть `/28` даёт 16 адресов, из которых 14 доступны для хостов — идеально для малых сетей.

#### Примеры использования CIDR

Допустим, у вас есть крупная сеть `10.0.0.0/8`, и вам нужно её разделить:
- `10.0.0.0/16` — подсеть с 65536 адресами.
- `10.0.1.0/24` — подсеть с 256 адресами.
- `10.0.1.128/25` — подсеть с 128 адресами.

Таким образом, CIDR позволяет разбивать крупные сети на меньшие и гибко управлять адресным пространством, применяя подход "бесклассовой адресации".

### 2. VLSM (Variable Length Subnet Masking)

**VLSM** — это метод создания подсетей с переменной длиной маски в пределах одной сети. Он позволяет создавать подсети разного размера в зависимости от потребностей, что помогает эффективно использовать IP-адреса.

#### Основные принципы VLSM

- **Гибкость в делении**: VLSM позволяет применять маски разной длины для подсетей в одной и той же сети. Например, внутри сети `192.168.1.0/24` можно создать подсети `/26`, `/28` и так далее, каждая из которых будет иметь разное количество IP-адресов.
- **Оптимизация использования адресов**: VLSM предотвращает расточительное использование IP-адресов, выделяя точное количество адресов для каждой подсети.
- **Требования к маршрутизатору**: Для работы с VLSM маршрутизатор должен поддерживать маршрутизацию с переменной длиной маски, что позволяет направлять трафик к правильной подсети.

#### Примеры использования VLSM

У вас есть сеть `192.168.1.0/24`, и вы хотите разделить её на несколько подсетей разного размера:
1. **Подсеть для большого отдела (50 устройств)**:
   - Используем `192.168.1.0/26`, что даёт 64 адреса (из них 62 для хостов).
2. **Подсеть для небольшого отдела (10 устройств)**:
   - Используем `192.168.1.64/28`, что даёт 16 адресов (из них 14 для хостов).
3. **Подсеть для пары устройств**:
   - Используем `192.168.1.80/30`, что даёт 4 адреса (2 для хостов).

---

### Отличия между CIDR и VLSM

- **CIDR** (Classless Inter-Domain Routing) — метод, позволяющий разбивать крупные сети на подсети произвольного размера с использованием бесклассовой адресации.
- **VLSM** (Variable Length Subnet Masking) — метод, который позволяет делить сеть на подсети разного размера, используя маски переменной длины в пределах одной сети.

### Заключение

- **CIDR** помогает гибко управлять крупными адресными пространствами, создавая сети с нужным количеством адресов.
- **VLSM** позволяет использовать маски переменной длины внутри одной сети, создавая подсети разного размера для различных нужд и предотвращая потери IP-адресов.

Эти два метода широко используются для эффективного управления IP-адресами в современных сетях и помогают лучше организовать сетевую инфраструктуру.
